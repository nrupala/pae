# PAE Portfolio Analytics — Google Sheets Import Guide

Companion to `pae_portfolio_analytics.xlsx` (generated by `tools/build_workbook.py`).

## Import steps

1. Go to [Google Sheets](https://sheets.google.com) → **File → Import**.
2. Choose the **Upload** tab and select `pae_portfolio_analytics.xlsx`.
3. Under "Import location" pick **Replace spreadsheet** (or "Create new
   spreadsheet"), then **Import data**.
4. Sheets recomputes every formula on import — the numbers you see are live
   formulas, not pasted values. (The .xlsx also carries cached values so
   Excel shows correct numbers on first open.)

## What works

- **All formulas are Google-Sheets-native.** The workbook deliberately uses
  only functions that exist in both Excel and Google Sheets: `STDEV`,
  `AVERAGE`, `SUM`, `SUMPRODUCT`, `SUMIF`, `COUNTIF`, `SMALL`, `INDEX`,
  `MAX`, `MIN`, `SQRT`, `IF`, `ROWS`. No `XLOOKUP`, no `LET`/`LAMBDA`, no
  dynamic-array-only functions.
- **Amber cells are the inputs** (holdings, prices, returns, risk-free rate,
  factor exposures, shock %). Everything else calculates.
- Cross-sheet references (`RISK!`, `DASHBOARD!`, `INPUT_Holdings!`,
  `RETURNS!`, `SCENARIOS!`) import unchanged.

## Known limits

- **24-month sample window.** `RETURNS` holds 24 fictional monthly returns
  (Jan 2024 – Dec 2025, clearly labeled SAMPLE). To use your own history:
  overwrite column C (keep one return per row), and if you add rows beyond
  row 27, extend the ranges in the `RISK` formulas (`C4:C27` → your last
  row) and fill down the helper columns D–G on `RETURNS`.
- **VaR/CVaR are rank-based, not interpolated.** They implement the PAE
  engine definition (`engine/src/risk/metrics.rs`): VaR 95% =
  −(2nd-worst of 24 months); CVaR 95% = average loss beyond that rank.
  This intentionally differs from Sheets' `PERCENTILE` (which interpolates).
- **Manual factor exposures.** The `FACTORS` sheet is a simplified
  attribution (contribution = exposure × factor return). The full OLS
  regression — betas, t-stats, R², variance decomposition — runs only in
  the PAE Python engine (`analytics/pae/models/factor.py`).
- **Stylized stress shocks.** `SCENARIOS` replays historical shock profiles
  from `engine/src/risk/stress.rs` (GFC 2008, COVID 2020, 2022 rate shock).
  Shocks are editable; they are stylized history, not forecasts. Cash is
  modeled at 0% shock (the engine has no cash profile).
- **Sample data is fictional.** All pre-filled holdings and returns are
  SAMPLE data. Replace before drawing conclusions.
- **No macros, no scripts.** Pure formulas + formatting; nothing to authorize.

## Disclosure (restated from the DISCLOSURE sheet)

This spreadsheet is a **standalone educational companion** to the PAE
framework. **It is NOT zero-knowledge encrypted** — unlike the PAE
application, anything you type here is stored in **plain text** inside this
file. Do not enter passwords, account numbers, or data you would not want
readable by anyone who obtains the file.

**Educational analytics only: this tool calculates, you decide.** Nothing
here is investment advice or a buy/sell recommendation. Past returns do not
predict future results.

## Regenerating

The workbook is a build artifact — do not hand-edit and re-upload as the
source of truth. Change `tools/build_workbook.py`, re-run it, and re-import:

```bash
python3 tools/build_workbook.py      # regenerates the .xlsx (idempotent)
python3 tools/verify_workbook.py     # 159 checks: formulas vs engine logic
```
